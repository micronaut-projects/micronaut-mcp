Table 6. Configuration Properties for McpServerInfoConfigurationProperties
Property Type Description Default value

java.lang.String

micronaut.mcp.server.info.version

java.lang.String

micronaut.mcp.server.info.title

java.lang.String

A human-readable title of the server, for display

micronaut.mcp.server.info.description

java.lang.String

A description of the server

micronaut.mcp.server.info.website-url

java.lang.String

The URL of the website of the server. It must be an https or http URL without a user name or password, or the startup fails.

micronaut.mcp.server.info.icons

java.util.List

The icons of the server. Each icon has a required src (an HTTPS URL or a data:image/…​ URI; an HTTP URL is accepted, another scheme or a URL with a user name or password fails the startup) and an optional mime-type, sizes (for example 48x48 or any) and theme (light or dark, in lowercase).

micronaut.mcp.server.info.instructions

java.lang.String

Instructions describing how to use the server and its features, which clients may add to the model’s prompt. Every client that connects can read them, so do not put secrets in them.

Table 7. Configuration Properties for PromptsConfigurationProperties
Property Type Description Default value

micronaut.mcp.server.prompts.list-changed

boolean

whether the prompts capability is advertised even when the server has no prompts, so prompts can be added at runtime, and, over STDIO, whether the server notifies clients when the list of prompts changes. The HTTP transport always advertises listChanged as false. Default value false.

Table 8. Configuration Properties for ResourcesConfigurationProperties
Property Type Description Default value

micronaut.mcp.server.resources.subscribe

boolean

whether the client can subscribe to be notified of changes to individual resources. It does not advertise the resources capability when the server has no resources unless list-changed is also true. The HTTP transport always advertises subscribe as false. Default value false.

micronaut.mcp.server.resources.list-changed

boolean

whether the resources capability is advertised even when the server has no resources, so resources can be added at runtime, and, over STDIO, whether the server notifies clients when the list of resources changes. The HTTP transport always advertises listChanged as false. Default value false.

Table 10. Configuration Properties for TransportSecurityConfigurationProperties
Property Type Description Default value

micronaut.mcp.server.transport-security.enabled

boolean

Whether the Origin and MCP-Protocol-Version request headers of the HTTP endpoint are validated. Default value true.

micronaut.mcp.server.transport-security.allow-loopback-origins

boolean

Whether loopback origins (localhost, 127.0.0.1 and [::1], with http or https and any port) are allowed. Default value true.

micronaut.mcp.server.transport-security.allowed-origins

java.util.List

The origins allowed besides loopback origins, such as https://app.example.com, each scheme://host[:port] without a path. * allows every origin. None by default.
