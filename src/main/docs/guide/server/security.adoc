=== Transport security

The HTTP endpoint validates two request headers, as the https://modelcontextprotocol.io/specification/2025-11-25/basic/transports#security-warning[Streamable HTTP transport] requires:

- `Origin`, to prevent DNS rebinding attacks. A request whose `Origin` is not allowed is answered with `403 Forbidden`. Loopback origins (`localhost`, `127.0.0.1` and `[::1]` on any port) are allowed, and so are requests without an `Origin`, which browsers always send. Allow the origins of browser-based clients with `allowed-origins`, or `*` for any origin.
- `MCP-Protocol-Version`. A request with a version the server does not support is answered with `400 Bad Request`.

[configuration]
----
micronaut:
  mcp:
    server:
      transport-security:
        allowed-origins:
          - https://app.example.com
----

=== Authorization

Secure the MCP endpoint with https://micronaut-projects.github.io/micronaut-security/latest/guide/[Micronaut Security]. MCP clients authenticate with OAuth 2.1 bearer tokens, so add `micronaut-security-jwt` to validate the tokens and `micronaut-security-oauth2`, which implements the https://modelcontextprotocol.io/specification/2025-11-25/basic/authorization[authorization discovery] the specification requires:

- an unauthenticated request is answered with `401 Unauthorized` and a `WWW-Authenticate: Bearer resource_metadata="..."` challenge;
- the https://www.rfc-editor.org/rfc/rfc9728[OAuth 2.0 Protected Resource Metadata] of the endpoint is served at `/.well-known/oauth-protected-resource/mcp`, naming the authorization servers of the configured OpenID clients.

[configuration]
----
micronaut:
  security:
    token:
      jwt:
        signatures:
          jwks:
            idp:
              url: https://idp.example.com/.well-known/jwks.json
    oauth2:
      clients:
        idp:
          openid:
            issuer: https://idp.example.com
    intercept-url-map:
      - pattern: /mcp
        access:
          - isAuthenticated()
----

Tools, prompts and resources receive the authenticated principal through the <<context, transport context>>:

[source,java]
----
@Tool
String whoami(MicronautMcpTransportContext context) {
    return context.principal().getName();
}
----
