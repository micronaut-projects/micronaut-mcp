Via configuration, you should define your mcp server name and version. You can also give it a title, a description, a website URL, icons, and instructions that clients may add to the model's prompt:

[configuration]
----
micronaut:
  mcp:
    server:
      info:
        name: weather
        version: 1.0.0
        title: Weather
        description: Forecasts by city
        website-url: https://example.com
        icons:
          - https://example.com/weather.png
        instructions: Ask for a city before asking for a forecast.
----
