In a method annotated with `@ResourceCompletion`, you can use as a return type:

- `io.modelcontextprotocol.spec.McpSchema.CompleteResult`
- `List<String>`

The method can also answer later. If it returns a `CompletionStage`, such as a `CompletableFuture`, or a reactive type that emits one item, such as a Reactor `Mono`, the completion is what that completes with, in any of the types above. A reactive type that emits several `String` items, such as a `Flux<String>`, is collected into the list.
