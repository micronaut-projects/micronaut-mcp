The preferred way to declare a prompt completion is using a method annotated with api:mcp.annotations.PromptCompletion[] in a `@Singleton` bean.

snippet::io.micronaut.mcp.docs.completions.prompts.MyPromptsCompletions[project-base="test-suite-docs", tags="clazz"]

NOTE: You need a prompt with the same name as the completion prompt. Moreover, the name of the prompt completion argument must match the name of the prompt argument.

WARNING: Defining a prompt completion via an annotation currently does not work with https://docs.micronaut.io/latest/guide/#eagerInit[eager initialization of singletons].
