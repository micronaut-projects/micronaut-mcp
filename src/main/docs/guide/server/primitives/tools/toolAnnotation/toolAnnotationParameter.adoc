The method parameter names will be automatically used as the tool argument names, unless you use the api:mcp.annotations.ToolArg[] annotation to differentiate the tool argument name from the method parameter name.

snippet::io.micronaut.mcp.docs.tools.toolarg.Tools[project-base="test-suite-docs", tags="fakepackage,imports,clazz"]

In a method annotated with `@Tool` you can bind parameters with types:

- api:mcp.server.context.MicronautMcpTransportContext[]
- A class or Java record defined as the tool <<Input JSON Schema,toolsInputJsonSchema>>.
- `io.modelcontextprotocol.spec.McpSchema.CallToolRequest`.


A parameter whose type is defined as the tool <<toolsInputJsonSchema, input JSON Schema>> is the whole tool input. Annotate it with api:mcp.annotations.ToolArg[] to make it a named property of the tool input instead. The JSON Schema of its type is then used as the schema of that property.
