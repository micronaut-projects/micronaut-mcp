The preferred way to declare a tool is using a method annotated with api:mcp.annotations.Tool[] in a `@Singleton` bean.

snippet::io.micronaut.mcp.docs.tools.Tools[project-base="test-suite-docs", tags="fakepackage,imports,clazz"]

By default, the method name is used as the tool name.
You can override this by setting the `name` attribute of the `@Tool` annotation.

NOTE: The Python method name is used verbatim, so the tool of the previous example is named `fen_evaluation`. Set the `name` attribute of the `@Tool` annotation to expose a different name.
