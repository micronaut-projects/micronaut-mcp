With https://micronaut-projects.github.io/micronaut-micrometer/latest/guide/[Micronaut Micrometer] on the classpath, the server times every tool call, prompt get, resource read and completion with a timer named `mcp.server.operation.duration`, following the https://opentelemetry.io/docs/specs/semconv/gen-ai/mcp/[OpenTelemetry semantic conventions for MCP]:

|===
|Tag |Value

|`mcp.method.name`
|The JSON-RPC method: `tools/call`, `prompts/get`, `resources/read` or `completion/complete`

|`mcp.primitive.name`
|The name of the tool or prompt, the URI of the resource, or the URI template of the resource template

|`error.type`
|`none`, `tool_error` for a tool execution error, or the class of the exception that ended the operation
|===

Disable the timer with `micronaut.mcp.server.metrics.enabled=false`.

To observe operations otherwise, for example to trace them, register a bean of type `McpServerObserver`: it is notified when each operation starts and ends.
