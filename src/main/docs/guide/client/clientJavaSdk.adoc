To use MCP Clients powered by the https://github.com/modelcontextprotocol/java-sdk[MCP Java SDK], use the following dependency:

dependency:micronaut-mcp-client-java-sdk[groupId=io.micronaut.mcp]

It creates a client for each HTTP connection of `micronaut.mcp.client.http`, using its `url`, and its `timeout` as the request timeout of the client.

NOTE: The `headers`, `initialization-timeout`, `request-timeout`, `auto-health-check`, `log-requests` and `log-responses` settings of a connection, and the STDIO connections of `micronaut.mcp.client.stdio`, are only used by the <<clientLangchain4j, LangChain4j MCP Client>>.

Additionally, if you are building an <<serverJavaSdk, MCP Server>>, you can test it by injecting a bean of type `io.modelcontextprotocol.client.McpSyncClient` or `io.modelcontextprotocol.client.McpAsyncClient` in your tests. The MCP Client pointing to your MCP Server has a https://docs.micronaut.io/latest/guide/#qualifiers[name qualifier] with value `embeddedServer`.

To customize client creation for your application's needs, define
https://docs.micronaut.io/latest/api/io/micronaut/context/event/BeanCreatedEventListener.html[BeanCreatedEventListener]s
for `HttpClientStreamableHttpTransport.Builder`, `McpClient.SyncSpec`, or `McpClient.AsyncSpec`.
